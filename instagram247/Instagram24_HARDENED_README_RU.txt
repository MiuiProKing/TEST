INSTAGRAM 24/7 AUTOPAIR — УСТАНОВКА НА ALLPREDICTOR
==================================================

В комплекте:
1) Instagram-24-7-AUTOPAIR-unsigned.ipa — приложение iPhone без подписи.
2) Instagram24_Server_AUTOPAIR.py — парный серверный файл для Dashboard.

ГЛАВНОЕ ИЗМЕНЕНИЕ
-----------------
Код из логов больше не нужен. Во время сборки создаётся отдельный случайный
ключ и автоматически встраивается только в эти два парных файла. IPA сразу
находит свой Python-сервер и привязывает первый iPhone.

ВАЖНО О БЕЗОПАСНОСТИ
--------------------
- Не публикуй и не передавай другим людям собранный Python-файл: внутри него
  находится приватный ключ именно этого IPA.
- Логин и пароль Instagram не вписаны в Python, IPA или GitHub.
- Пароль вводится в IPA и сохраняется в Keychain iPhone.
- На сервер он передаётся по AES-GCM и хранится только внутри AES-GCM vault.
- Vault-key хранится только в Keychain iPhone и не записывается сервером.
- Команды дополнительно подписываются отдельным P-256 ключом iPhone.
- Сервер принимает только первое привязанное устройство.

1. ALLPREDICTOR DASHBOARD
------------------------
Сначала останови старый Instagram Python, чтобы одновременно не работали две
версии. Загрузи новый файл Instagram24_Server_AUTOPAIR.py через Dashboard и
запусти его. Никакой код в логах искать не нужно.

Файл сам установит requests, cryptography и instagrapi 2.18.17. Нужен Python
3.10 или новее. Если Dashboard задаёт PORT, сервер автоматически откроет
health endpoint /health.

Dashboard должен сохранять созданные рядом файлы instagram247_device.json,
instagram247_session.enc, instagram247_seen.json и instagram247_settings.json
между перезапусками.

2. УСТАНОВКА IPA
----------------
Подпиши Instagram-24-7-AUTOPAIR-unsigned.ipa своим сертификатом и установи на
iPhone. Можно установить поверх предыдущей версии с тем же bundle ID.

При открытии IPA автоматически:
1) подключится к парному Python-серверу;
2) привяжет ключ этого iPhone;
3) разблокирует зашифрованный vault;
4) запросит статус сервера.

Логин уже подставлен. Введи актуальный пароль только в IPA и нажми
«ВОЙТИ INSTAGRAM». Если Instagram запросит 2FA, введи одноразовый код и нажми
«ОТПРАВИТЬ КОД 2FA». Дождись статуса «ONLINE 24/7».

После запуска IPA можно закрыть: Realtime MQTT и keepalive выполняет Python.
После перезапуска Python просто открой IPA — оно снова разблокирует vault.

3. НАСТРОЙКА INSTAGRAM
----------------------
В официальном Instagram должен быть включён параметр «Показывать статус в сети».
Не выполняй много повторных входов подряд: Instagram может запросить проверку
безопасности. Подтверди её в официальном приложении и повтори позже.

ОГРАНИЧЕНИЕ
-----------
Используется неофициальный Instagram private Realtime MQTT. Сервер отправляет
foreground-state и keepalive, но окончательное решение о зелёной точке принимает
Instagram. Гарантировать её непрерывное отображение невозможно.

СБРОС ПРИВЯЗКИ
--------------
Если нужен другой iPhone, останови сервер и удали instagram247_device.json и
instagram247_session.enc. После запуска открой IPA на новом iPhone и выполни
вход Instagram заново.
