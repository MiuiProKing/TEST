INSTAGRAM 24/7 HARDENED — УСТАНОВКА
===================================

В комплекте:
1) Instagram-24-7-HARDENED-unsigned.ipa — приложение iPhone без подписи.
2) Instagram24_Server_HARDENED_PAIRED.py — единственный серверный файл.

ВАЖНО О БЕЗОПАСНОСТИ
--------------------
- Логин и пароль Instagram НЕ вписаны в Python, IPA или публичный репозиторий.
- Пароль вводится один раз в IPA и сохраняется в Keychain этого iPhone.
- На сервер он передаётся по AES-GCM и хранится только внутри AES-GCM vault.
- Vault-key хранится только в Keychain iPhone и не записывается сервером.
- Команды подписываются отдельным P-256 ключом iPhone.
- Сервер принимает только первое привязанное устройство.

1. ЗАПУСК PYTHON НА ХОСТИНГЕ
---------------------------
Загрузи Instagram24_Server_HARDENED_PAIRED.py в отдельную постоянную папку.

Команда запуска:
python3 Instagram24_Server_HARDENED_PAIRED.py

При первом запуске файл сам установит requests, cryptography и instagrapi 2.18.17.
Нужен Python 3.10 или новее. Если хостинг задаёт PORT, сервер автоматически
откроет безопасный health endpoint /health.

В первых строках закрытого лога появится:
КОД ПРИВЯЗКИ ДЛЯ IPA: ...

Скопируй код. Не публикуй его и не отправляй другим людям. Файл
instagram247_pair_secret.txt и остальные созданные сервером файлы должны
сохраняться между перезапусками.

2. УСТАНОВКА IPA
----------------
IPA unsigned: сначала подпиши его своим сертификатом через привычный сервис,
затем установи на iPhone.

Открой Instagram 24/7:
1) вставь код из лога Python в поле «Код из логов Python-сервера»;
2) нажми «ПРИВЯЗАТЬ И РАЗБЛОКИРОВАТЬ»;
3) логин уже подставлен — введи актуальный пароль только в приложении;
4) нажми «ВОЙТИ INSTAGRAM»;
5) если Instagram запросит 2FA, введи одноразовый код и нажми
   «ОТПРАВИТЬ КОД 2FA»;
6) дождись статуса «ONLINE 24/7».

После успешного запуска IPA можно закрыть: Realtime MQTT и keepalive выполняет
Python-сервер. После перезапуска Python открой IPA — оно разблокирует vault и
восстановит сессию автоматически.

3. НАСТРОЙКА INSTAGRAM
----------------------
В официальном Instagram должен быть включён параметр «Показывать статус в сети».
Не выполняй много повторных входов подряд: Instagram может запросить проверку
безопасности. Если она появилась, подтверди вход в официальном приложении и
повтори попытку позже.

ОГРАНИЧЕНИЕ
-----------
Используется неофициальный Instagram private Realtime MQTT. Сервер отправляет
foreground-state и keepalive, но окончательное решение о зелёной точке принимает
Instagram. Гарантировать её непрерывное отображение невозможно.

СБРОС ПРИВЯЗКИ
--------------
Если iPhone потерян или приложение переустановлено с очисткой Keychain, останови
сервер и удали его файлы instagram247_device.json, instagram247_session.enc,
instagram247_pair_secret.txt, instagram247_seen.json и instagram247_settings.json.
После нового запуска появится новый код, а вход Instagram потребуется выполнить
заново.
