TELEGRAM 24/7 — iPhone + Python сервер

1. Подпиши и установи Telegram-24-7-unsigned.ipa.
2. На сервер / AllPredictor загрузи ИМЕННО Telegram24_Server_PAIRED.py из того же пакета.
3. Запусти Python-файл.
4. Получи API ID и API HASH на my.telegram.org (API Development Tools).
5. В приложении введи API ID, API HASH и свой номер телефона.
6. Нажми «ПОЛУЧИТЬ КОД».
7. Код, присланный Telegram, введи в поле «Код Telegram» и подтверди.
8. Если Telegram попросит двухэтапный пароль — введи 2FA и нажми подтверждение.
9. После успешного входа «ОНЛАЙН 24/7» включается автоматически.

БЕЗОПАСНОСТЬ
- Код и пароль 2FA не сохраняются приложением и сервером.
- Команды между iPhone и сервером шифруются AES-GCM.
- Telegram StringSession хранится на сервере только в зашифрованном виде.
- Кнопка «ОТКЛЮЧИТЬ ЭТУ СЕРВЕРНУЮ СЕССИЮ» вызывает Telegram log_out и удаляет локальную сессию сервера.
- Никому не отправляй paired Python-файл или установленный IPA: они образуют одну приватную пару.
- Никакое приложение не может защитить Telegram-сессию от владельца/администратора самого сервера, если сервер злонамеренный: он исполняет код и технически может читать память процесса. Используй хостинг, которому доверяешь.

ВАЖНО
- Сообщения в «Избранное» каждую секунду НЕ отправляются. Это специально, чтобы не получить FloodWait/ограничения Telegram.
- Сервер обновляет online-status примерно раз в 25 секунд.
- Telegram сам определяет отображение online/last seen с учётом приватности и серверных правил, поэтому абсолютную гарантию «вечного зелёного статуса» дать нельзя.
- Бесплатный хостинг может усыплять процесс. Если он остановит Python, онлайн тоже остановится.
